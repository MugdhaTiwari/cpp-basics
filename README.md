# C++ Basics

This repository documents my journey of learning C++ programming from the fundamentals.

It contains beginner-friendly programs, mini-projects, and practice problems that help build a strong understanding of programming concepts before moving on to Data Structures and Algorithms.

## Repository Structure

### 01_Operators

Programs based on:

* Arithmetic Operators
* Relational Operators
* Logical Operators

### 02_Conditional Op

Programs using:

* if
* if-else
* nested if
* switch statements

### 03_Loops

Programs using:

* for loops
* while loops
* do-while loops

### 04_Arrays

Programs based on array operations and problem solving.

### 05_Mini Projects

Small projects built using basic C++ concepts.

Examples:

* Number Guessing Game
* Rock Paper Scissors

## Concepts Covered

* Input and Output
* Data Types and Variables
* Operators
* Conditional Statements
* Loops
* Arrays
* Strings
* Functions
* Pointers
* Dynamic Memory Allocation
* Object-Oriented Programming
